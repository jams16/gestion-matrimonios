# Evidencias: invitados

## Objetivo

Verificar las reglas del módulo de invitados, RSVP, requerimientos, pases, mesas, asignaciones, catálogos y pertenencia al matrimonio.

## Comando

`pnpm.cmd test -- --runInBand src/modules/invitados/application/invitados.service.spec.ts`

Los artefactos de `automatico/` contienen el resultado de esta ejecución aislada; no crean ni modifican registros de la base de datos.
