# HU17 - Gestionar hitos significativos

La HU cubre consulta, registro y edicion de hitos, y la asociacion explicita
de una o mas actividades que permiten hacer seguimiento de su cumplimiento.

- Pruebas automaticas: `automatico/casos.spec.ts`
- Casos manuales: `manual/casos-manuales.md`
- Evidencia producida por ejecucion: `evidencias/`

| Caso | CA | Cobertura |
|---|---|---|
| CP-E04-HU17-01 | CA081, CA082 | Registrar y listar hitos del matrimonio. |
| CP-E04-HU17-02 | CA083 | Editar informacion de un hito. |
| CP-E04-HU17-03 | CA084, CA085 | Asociar actividades y consultarlas desde el hito. |
