# HU15 - Registrar y organizar actividades y checklist

Esta HU valida el ciclo completo de una actividad del cronograma: registro,
incorporacion al matrimonio, checklist, edicion y consulta aislada.

- Pruebas automaticas: `automatico/casos.spec.ts`
- Casos manuales: `manual/casos-manuales.md`
- Evidencia producida por ejecucion: `evidencias/`

| Caso | CA | Cobertura |
|---|---|---|
| CP-E04-HU15-01 | CA071, CA072 | Crear y listar actividad del matrimonio. |
| CP-E04-HU15-02 | CA073 | Crear item de checklist asociado. |
| CP-E04-HU15-03 | CA074 | Editar actividad e item de checklist. |
| CP-E04-HU15-04 | CA075 | Consultar checklist sin mezclar actividades. |
