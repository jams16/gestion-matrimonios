# HU23 - Generar y organizar el timing del dia de la boda

La HU cubre la generacion desde una hora inicial, el encadenamiento por
duracion, el alta manual, la edicion y la consulta actualizada del timing.

- Pruebas automaticas: `automatico/casos.spec.ts`
- Casos manuales: `manual/casos-manuales.md`
- Evidencia producida por ejecucion: `evidencias/`

| Caso | CA | Cobertura |
|---|---|---|
| CP-E04-HU23-01 | CA110, CA111 | Generar horarios secuenciales desde una hora inicial. |
| CP-E04-HU23-02 | CA112 | Agregar actividad manual al timing. |
| CP-E04-HU23-03 | CA113 | Editar hora de inicio y duracion. |
| CP-E04-HU23-04 | CA114 | Consultar timing con horarios y duraciones vigentes. |
